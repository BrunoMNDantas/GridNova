# GridNova

An open-source, extensible and configurable React data grid.

> Early development: not yet published to npm.

## Development

Requires Node 24 and pnpm (`corepack enable`).

```sh
pnpm install
pnpm dev        # playground at http://localhost:5173
pnpm test       # unit tests (watch mode)
pnpm build      # library build
```

Project decisions are recorded in [docs/decisions.md](docs/decisions.md).
